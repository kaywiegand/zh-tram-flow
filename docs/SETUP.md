# Setup & Deployment — Zürich Tram Flow

---

## Prerequisites

- Python 3.10+
- [uv](https://docs.astral.sh/uv/) — fast Python package manager

---

## Local Setup

```bash
# Clone
git clone https://github.com/kaywiegand/zh-tram-flow.git
cd zh-tram-flow

# Install — analysis + ML dependencies
uv sync --extra dan --extra dsc

# Launch notebooks
jupyter lab
```

> **Note:** Raw data is not included in this repo (541 MB Parquet).
> Data engineering is documented in [`sf_data-research`](https://github.com/kaywiegand/sf_data-research).
> To run prediction notebooks, download `data/processed/train_final_v2.parquet` and `test_final_v2.parquet` from the release assets.

### GitHub Pages

The `/public` folder is deployed as a static website.

**One-time setup:**
1. Go to **Settings → Pages**
2. Source: **Deploy from a branch** · Branch: `main` · Folder: `/public`
3. Click **Save** — deploys automatically on every push to `main`

### Streamlit Cloud

**One-time setup:**
1. Go to https://share.streamlit.io — sign in with GitHub
2. New app → Repository: `kaywiegand/zh-tram-flow` · Branch: `main` · File: `apps/dashboard/app.py`
3. Click **Deploy**

> Before deploying: ensure `apps/dashboard/data/*.parquet` files are committed. Generated by `apps/dashboard/precompute.py`.

## Retraining with New Data

No automated pipeline needed. For a new year (e.g. 2026):

1. Run [`sf_data-research`](https://github.com/kaywiegand/sf_data-research) pipeline → updates `data/raw/`
2. Re-run `02_preparation.ipynb` — cleaning + temporal split
3. Re-run `05_feature_engineering.ipynb` — feature construction + export
4. Re-run `06_prediction_2-model.ipynb` (v1) and `06_prediction_4-model_v2.ipynb` (v2)
5. Update split boundary (2025 = test year → 2026 = test year)

## Production Notes

### `prev_trip_delay` in Live Inference

`prev_trip_delay` drives the main improvement (45.7s → 18.56s MAE). In a live inference scenario it requires **real-time trip tracking**.

| Scenario | Feasibility |
| :--- | :--- |
| Dashboard / batch prediction | ✅ — aggregate previous run's delay before predicting |
| True live inference (next stop) | ⚠️ — requires live feed of current trip positions |
| Fallback if unavailable | LightGBM v1 (45.7s) or Stop Mean (50.0s) |
